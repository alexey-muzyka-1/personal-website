# 0009. Атрибуция только дописывается

Статус: принято

## Что заставило

Если хранить источник полем у пользователя, повторный `/start` из другого
Reel затрёт первый. История «пришёл из А, вернулся из Б» исчезнет, а
именно она отвечает, что человека привело.

## Решение

Касания источника пишутся в отдельную таблицу и только добавляются.
Первая строка — первое касание, и она неизменна; последняя — самое
свежее. Атрибуция пишется на каждый `/start`, включая повторный и пустой.

В отчётах источником человека считается **первое непустое** касание: важно,
что его привело, а не куда он потом возвращался. Правило одно для всех
таблиц, иначе «людей из site_home» в разных отчётах считалось бы
по-разному.

## Чем платим

Строк больше, чем людей. Взамен ничего не теряется и битую метку видно:
сырое значение кладётся в событие, даже когда сама метка не сохранилась.
