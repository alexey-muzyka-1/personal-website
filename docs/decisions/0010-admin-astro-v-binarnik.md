# 0010. Админка на Astro, вшитая в бинарник

Статус: принято, заменило серверный HTML-шаблон

## Что заставило

Одна страница на шаблоне Go упёрлась в потолок: ни графиков, ни разделов,
ни способа посмотреть, что бот показывает людям. Правки вёрстки означали
пересборку Go.

Очевидный ход — поднять Astro отдельным сервисом. Это Node в проде:
второй контейнер, второй рантайм и второй способ уронить машину. А если
бы он ходил в базу сам, схему базы лидов знали бы двое.

## Решение

Astro собирает статику, она вшивается в бинарник через `go:embed`, данные
приходят с `/admin/api/*`. Схему знает только Go; вёрстка правится и
пересобирается без него. Node остаётся в сборке, в прод не попадает.

Несобранный интерфейс не роняет процесс: бот — это в первую очередь
webhook. Вместо белого экрана показывается страница с командой сборки.

Своей авторизации у админки нет: пароль спрашивает Caddy.

## Чем платим

Сборка идёт в два слоя Docker, и на дроплете крутится npm. Взамен деплой
остаётся одним артефактом, который нечем выкатить наполовину.
