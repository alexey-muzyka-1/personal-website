# 0011. Карта бота и «Сообщения» собираются прогоном кода

Статус: принято

## Что заставило

Документ «что отвечает бот», написанный руками, устаревает на первой же
правке текста и врёт молча.

## Решение

`BOTMAP.md` собирается прогоном настоящего сценария на памяти:
`go run ./cmd/botmap`. Тест падает, если файл разошёлся с кодом.

Страница «Сообщения» в админке делает то же самое живьём: показывает
реплики, кнопки, все три ветки и что каждый шаг пишет в базу.

## Чем платим

Два обходчика сценария вместо одного. Разойтись с ботом ни один из них не
может — оба берут текст из ответа воронки, — но покрытие веток у них
может отличаться, и это надо помнить при добавлении новой ветки.
