# 0014. Строки собираются по именам колонок

Статус: принято, после реального бага

## Что заставило

Строки собирались по порядку полей. В одном запросе `stage` стоял перед
`source`, а в структуре — наоборот. Обе колонки текстовые, ошибки не
возникало: значения молча менялись местами. На живой странице колонка
«Состояние» была пустой, а в «Откуда» лежало `not_shipping`.

Такой баг не ловится ни компилятором, ни глазами при чтении диффа.

## Решение

Строки собираются по именам колонок. Несовпадение роняет запрос, а не
искажает данные.

## Чем платим

Каждой колонке нужен явный алиас, а полям — теги. Взамен целый класс
ошибок перестал существовать.
