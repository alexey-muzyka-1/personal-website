# 0017. Списка подписчиков не существует, отсюда три когорты

Статус: принято, граница задана Telegram

## Что заставило

Хочется одну цифру: «конверсия из бота в подписку». Bot API её посчитать
не даёт.

Доступны только общее число подписчиков, статус конкретного известного
нам человека и события входа-выхода **с того момента, как бот стал
админом**. Списка участников нет ни целиком, ни постранично.

## Решение

Люди делятся на когорты, и складывать их в одну цифру запрещено:

- подписались после бота — это и есть работа воронки;
- были подписаны раньше замера;
- подписались неизвестно когда — статус есть, даты нет.

Дата подписки не подставляется «сегодняшним числом» тем, у кого её нет:
иначе первая же сверка нарисовала бы прирост на всю накопленную базу за
один день.

Бота обязательно держать админом канала. Потеря прав — самый дорогой
тихий сбой: в отчёте это выглядит как «никого не прибавилось», поэтому в
логе это ошибка, а не заметка.

## Чем платим

Красивой единой конверсии не будет никогда. Взамен ни одна из цифр не
врёт: на 21.08 в канале 674 человека, из них известны по имени трое —
те, кто приходил в бота.
