# 0018. Webhook регистрируется на каждом старте

Статус: принято, заменило регистрацию по флагу

## Что заставило

Регистрация была под переменной `TELEGRAM_SET_WEBHOOK`. Набор типов
update меняется вместе с кодом, а Telegram не дополняет прежний набор, а
заменяет его целиком. «Выкатить и не забыть один раз включить
переменную» — это способ остаться без половины событий и не узнать об
этом.

Так и вышло бы с подписками на канал: без явного `chat_member` они не
приходят вовсе, этот тип по умолчанию выключен.

## Решение

Адрес и список типов регистрируются на каждом старте, без флага.

Сбой регистрации не роняет процесс — адрес мог быть зарегистрирован
прошлым запуском. Но в логе это ошибка, а не заметка.

Накопившаяся очередь при перерегистрации не сбрасывается: за время
простоя в ней люди.

## Чем платим

Лишний вызов Bot API на старте.
