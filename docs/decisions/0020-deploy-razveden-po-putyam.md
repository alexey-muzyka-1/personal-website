# 0020. Деплой сайта и бота разведён по путям

Статус: принято, после того как сайт уехал незаметно

## Что заставило

Оба воркфлоу срабатывали на любой пуш в `main`. Мерж ботового PR
пересобирал и выкатывал сайт заодно — так изменение сайта однажды уехало
на прод, когда его никто не выкатывал.

## Решение

У каждого воркфлоу свой фильтр путей:

- сайт → `src/**`, `public/**`, `articles/**`, конфиг Astro, package-файлы;
- бот → `bot/**`.

Пересечения нет, поэтому мерж, затрагивающий обе половины, выкатывает обе
осознанно, а не одну случайно.

## Чем платим

Про фильтр надо помнить, добавляя новый каталог: файл вне списка не
вызовет деплой, и правка тихо доедет только со следующей чужой выкаткой.
