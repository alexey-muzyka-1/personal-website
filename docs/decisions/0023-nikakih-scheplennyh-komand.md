# 0023. Никаких сцепленных команд деплоя

Статус: принято, правило работы

## Что заставило

Команда `commit && push && pr create && pr merge` успела выполниться
целиком до того, как сработала отмена: владелец нажал стоп, а изменение
уже уехало на прод. Сцепленную команду нечем остановить на середине.

## Решение

`commit → стоп → подтверждение → PR → стоп → подтверждение → merge/deploy`.

Разрешение берётся **до** запуска, а не внутри. Исключений нет даже
когда на проде лежит сломанная версия: сказать об этом и ждать ответа.

## Чем платим

Больше кругов переписки. Взамен ни один шаг не уезжает раньше, чем его
разрешили.

Отдельная грабля из той же семьи: дожидаться деплоя по «последнему
прогону» нельзя. Если новый ещё не создан, проверка увидит предыдущий
успешный и отрапортует успех. Ждать нужно по конкретному идентификатору
запуска.
