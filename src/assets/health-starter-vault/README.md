# Health Starter Vault

Пустая структура для личной системы здоровья в Obsidian. Внутри нет медицинских данных, маршрутов и показателей автора.

Полный гайд: https://alexeymuzyka.com/articles/digital-health

## Быстрый старт

1. Установите Obsidian.
2. Откройте эту папку как новый vault через **Open folder as vault**.
3. В настройках Core plugins включите **Bases**, **Properties** и **Templates**.
4. Для Templates выберите папку `Health/_templates`.
5. Откройте `Health/Dashboard.md`.
6. Скопируйте `PROMPT-FOR-AGENT.md` в ChatGPT, Codex, Cursor или другой агент с доступом к локальным файлам.

Если у вас уже есть vault, не открывайте второй. Скопируйте папку `Health` в существующий vault и дайте агенту путь к нему.

## Что внутри

```text
Health/
├── Dashboard.md
├── Workouts.base
├── Schema.md
├── Workouts/
├── Plans/
├── Labs/
├── Metrics/
└── _templates/
```

Одна физическая сессия хранится в одном Markdown-файле. План и факт не смешиваются. Данные устройства дополняют ручную запись, но не перезаписывают самочувствие и заметки о технике.

## Приватность

- Не кладите ZIP/XML Apple Health, GPX-маршруты и оригиналы медицинских документов в публичный Git.
- Храните сырой экспорт отдельно от vault.
- Передавайте агенту только нужные файлы и агрегаты.
- AI помогает вести хронологию и готовить вопросы. Он не ставит диагноз.
